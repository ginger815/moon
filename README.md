# 🌕 中秋祝福页 · moon

一个纯静态的中秋互动祝福页：夜空烟花、明月、江南小镇剪影、玉兔与灯笼 ——
**点击灯笼输入你的名字，就能在屏幕正中领取一句专属祝福。**

在线地址：**https://ginger815.github.io/moon/**

> 基于 [kldby666/moon](https://github.com/kldby666/moon) 二次修改。

## ✨ 功能

- 🎆 点击任意处燃放烟花，支持爱心烟花、桂花飘落
- 🌕 月亮可拖动换位置，点击月亮发射烟花
- 🏮 **点击灯笼 → 输入名字 → 屏幕中央显示「名字，随机祝福语」**
- 🎵 背景音乐（本地文件，可手动播放）
- 📱 零依赖、零构建，断网也能跑（Tailwind / 图片 / 音乐全部本地化）

## 📁 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面本体（HTML + CSS + JS 单文件） |
| `tailwind.js` | 本地化的 Tailwind（原来是 CDN，改为本地以便离线/内网使用） |
| `music.mp3` | 背景音乐 |
| `yutu.png` | 玉兔图片 |
| `server.js` | 零依赖本地预览服务器（支持音频 Range 拖动） |
| `start.cmd` | Windows 双击启动并自动打开浏览器 |
| `使用说明.md` | 改动细节与本地运行/部署说明 |

## 🚀 本地运行

```powershell
cd moon
node server.js 8099
# 浏览器打开 http://127.0.0.1:8099/
```

Windows 也可直接双击 `start.cmd`。

## 🔧 本次相对原项目的改动

1. **删除顶部滚动弹幕**：移除「🌕 花好月圆 ❤️ 阖家团圆 …」跑马灯及其专用 CSS 动画。
2. **初始关闭自动模式**：打开页面不再自动持续放烟花；点「自动模式」或按空格仍可开启。
3. **新增「专属祝福」玩法**：点击灯笼弹出「输入你的名字领取专属祝福」，提交后弹窗关闭，
   屏幕正中以描金渐变字体显示「名字，随机祝福语」（10 条祝福随机且不连续重复）。
4. **资源本地化 + 静态服务器**：Tailwind、音乐、玉兔图改为本地文件，新增 `server.js` / `start.cmd`，
   使项目可以直接当作网址访问、也可整体发布到任意静态托管。
